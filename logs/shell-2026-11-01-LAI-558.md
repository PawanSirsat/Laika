**Decisions**
- Doubt never steals or signals: a liveness check that cannot complete counts
  as alive, and a recorded run with no start time is never treated as ours.
- `status` only reports leftovers; `stop` and `run` end them. A read command
  that kills processes would be a surprise.
- Grandchildren the harness detaches are not tracked. This is documented, and
  tested as surviving, rather than claimed.
