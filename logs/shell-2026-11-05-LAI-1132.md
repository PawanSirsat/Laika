**Decisions**
- The pane is a `::before`, never the element. `backdrop-filter` makes an element the
  containing block of its `position: fixed` descendants; the sidebar holds a fixed popover
  and catcher, the space bar a fixed menu, modals the Dropdowns portalled into them
  (LAI-726). Blurring the host would have trapped and clipped every one.
- Modal surfaces are translucent level 3 over a *blurred scrim*, not blurred themselves:
  one blur per modal, and a Dropdown inside stays real glass rather than a nested blur.
- Lanes and in-content cards are a tint, not a blur: only the smooth ambient gradient is
  behind them, so blur would cost GPU and change nothing visible. Keeps the board at 3
  blurred layers (sidebar, header where shown, space bar).
- Anything floating inside chrome (spaces popover, user menu) stays solid-on-glass — the
  "never nest" rule applied literally.
- Fallbacks swap tokens rather than restyle components, so every consumer follows.
- No ambient drift animation: every blurred layer above it would re-rasterise each frame.
- Matched the owner's references in docs/design/ (main checkout): ambient and dark glass to
  laika-brand-board.png (Ink→navy diagonal, Mist haze, corner discs with a line of light,
  fine-bordered translucent navy panels); light to laika-logo-light.png and
  laika-loaders.png (lavender-cast Paper, Glacier discs, white glass). No lavender in the
  dark background — the board keeps it for the mark.

**Discovered**
- The build's minifier folds `-webkit-backdrop-filter` and `backdrop-filter` into one
  declaration and keeps the last; with the prefixed line second, every blur was silently
  off in Chromium. Unprefixed only now, and the guard refuses a `-webkit-` twin.
- A `body` background paints above `body::before` at `z-index: -1` (it is an in-flow block
  background), which hid the ambient layer entirely. `html` keeps the canvas.
- No SidePanel on this branch holds a real Dropdown; the B16 test and the screenshot place
  a `.dd-panel` in a real SidePanel with the real stylesheet.
- Board-wide z-indexes outside the shared surfaces (board 30/31, timeline, my-day) are
  left as they were — moving them is O21's sweep, not this task.
