**Decisions**
- Busy and disabled-with-reason are `aria-disabled` + a swallowed click, not native
  `disabled` — native `disabled` blurs the button you just pressed (focus falls to
  `<body>`) and drops a reasoned button out of the tab order so its reason is never read.
  Implicit form submission fires a click on the default button, so the same swallow
  covers Enter-in-a-field.
- Busy is not dimmed (cursor `progress`, full opacity): faded reads "you can't", busy
  means "wait".
- Plain disabled stays native — out of the tab order, as the existing goldens expect.
- `Field` gained a `row` layout instead of space settings keeping its own label/input
  pair; it stacks again below 600px.
- `danger` stays the tinted variant; OffboardingDialog's solid red confirm moved to it
  (one danger look). Space settings' "pale violet disabled Save" moved to Button's
  standard disabled.
- Stroke stays 1.9 (the sidebar's), not the proposal's 1.75: refinement keeps the
  incumbent family.
- Guard is per migrated file with exact exception counts, not a global ratchet — a global
  count would turn red on every parallel branch that adds a button.
- Kept sidebar nav rows on NavIcon (pixel 18): moving them to Icon's 20px would shift the
  rail LAI-1123 just aligned, and sidebar.css is in PR #291.
