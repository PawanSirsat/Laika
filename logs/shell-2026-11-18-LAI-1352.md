**Decisions**
- Revision 3 lives in the marked block only — `projectBlock(origin, project,
  revision = 1)` — so the classic tab's unmarked block stays byte-for-byte
  (its CONTROL hash still holds) rather than changing a revision-1 text.
- The parent and child rule is rule 8, numbered, not a paragraph after the
  list, so the CLI and skill can refer to it as the block does rule 7.
- *+N* opens the viewer on the first file it hides, rather than unfolding the
  strip: every tile opens the viewer, and the viewer steps through all.

  the focus it held out of the dialog's trap.
- Unlisted files are drawn from the note's own links: `GET /unlisted` has no
  file list. A link written as an image is shown; anything else is a card,
  because a file the server would not serve inline downloads into a frame.

  production's CSP refuses the store in frames today, and it starts working by
  itself the day `frame-src` names the store.
- Comment images are gathered by a rehype step inside `TaskMarkdown`, behind a
  boolean (the props test's rule: no caller-supplied transform).

  two owners). Reported in PR #409 and to CHIEF; not filed here.
- Download of an inline file cannot be forced: the content route always serves
  an inline type inline, and `download` is ignored across the 302 to the store.
  A `?download=1` would settle it. Reported, not filed.
- `GET /unlisted` exposes no file metadata (name, type, size). Reported, not
  filed, as CHIEF asked for gaps in the report rather than a server route.

  transition's `finished` rejects: a screenshot that waits on "all animations"
  hangs or throws (only finite ones, rejections caught, in outputs.test.ts).
- The Connect golden's style digest moves with a prompt's length: the prompt is
  one `span` per line, so five new lines are five new style lines, each
  identical to the others. Diffed with `LAIKA_GOLDEN_DUMP` before regenerating.
