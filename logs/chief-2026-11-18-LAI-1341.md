**Decisions**
- **Every token is an agent.** `resolve-actor.ts` writes `actor_kind` `agent` for every token,
  so a person's own CLI token counts too. One with no registered agent reads as `Ada's agent`.
  That is the board's own definition of an agent, and I kept it.
- **The owner's digest carries their agent's work.** The decision moved "never the actor" to
  the human acting in person, and the digest's "done by someone else" is the same rule, so it
  follows. CHIEF may narrow it to instant mail only.
- **The wording is literal, even to the owner:** "Claude Code (Ada's agent) assigned you …",
  not "Your agent …", as the owner phrased it.
- **No migration.** Everything needed was already on the rows.

**Discovered**
- **A creator is not an implied watcher (§4.18).** Only the assignee, commenters and the
  people mentioned are. My first digest test assumed otherwise.
- **A registered agent needs `agent_project_grants` to write.** It is refused 403
  `agent_not_granted` otherwise.
- **Self-mentions are recorded** (`syncMentions` has no author filter). That is why an agent's
  @mention of its owner can mail them with no change to the writer.
