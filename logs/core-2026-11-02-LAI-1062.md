**Decisions**
- **Derived, not declared.** A flag written as `true` beside the routes would
  rot the same way `false` did. Reading the route table means an app without a
  database (`testApp()`) honestly reports all four off.
- **Protocol 2, min_client 1.** This follows the plan (§E.6 sample
  `whats_new: [{ protocol: 2 }]`) and `min_protocol_for: 2`. A protocol-1
  helper is still accepted and is told only which features it is missing.
