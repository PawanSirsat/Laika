**Decisions**

- **The §5 transition table splits by principal, and the seam is `actor.token`.**
  The obvious predicate, `isSystemPrincipal`, is *wrong*: it means
  `kind === 'system'` — cron and webhooks — so a token-bearing agent is an
  ordinary `ResolvedActor` and branching on it would have handed every MCP
  caller the widened rule. Checked rather than assumed.
- **The composite FK is `CASCADE`, not `RESTRICT`.** RESTRICT is the obvious
  choice and it is unsafe here: SQLite resolves cascades in **table-creation
  order**, and drizzle-kit emits tables alphabetically, so
  `board_column_statuses` is created first and a project delete then fails.
  Measured both orders both ways. RESTRICT's correctness would have rested on
  how two tables happen to be *named*.
- **The backfill gives existing projects five lanes, not the new four.**
  `DEFAULT_COLUMNS` folds `backlog` into "To do", which is the better default and
  would be a silent edit to a live board on upgrade.
- **`todo` leads "To do", not `backlog`.** The first status is the primary — what
  a drop sets and where the lane's colour comes from — and there is no
  `.lane-dot-backlog` rule, so the enum's order would have drawn a grey lane
  labelled "To do" that dropped cards into `backlog`.
- **A 404 from `/board-columns` falls back to one lane per status.** Rejected an
  error screen: a 404 is a server without the feature, and those five labels were
  already ours. It also keeps all 14 existing board fixtures green.
- **The View settings trigger lives in the space bar, not the slot below it.**
  First built in the slot; `sprint-strip.test.ts` caught that this adds a band
  the reference does not have. Moved rather than weakening the guard.
- **Group-by ships read-only.** A drop there is three endpoints with three
  permission checks and no keyboard equivalent. → LAI-288.
- **Seeds live in `db/`, not `services/`.** eslint caught `db/backfill.ts`
  importing `services/` — CONVENTIONS §2 makes `db/` the bottom layer.

**Discovered**

- `claimTask` writes `from: 'todo'` into an **append-only** activity row
  regardless of the task's real prior status, and stamps `started_at`
  unconditionally where `changeStatus` stamps only when null. Found while
  verifying the principal seam; unrelated to this diff.
  → **LAI-265** filed (`area: server`).
- **A project cannot be deleted at all today** — `activity.project_id` is
  `ON DELETE restrict` and `activity` is append-only by trigger. Not caused by
  this work; it is LAI-154's subject. My first test asserted the opposite and was
  rewritten to use a bare project row so it tests *these two tables* rather than
  quietly asserting somebody else's bug.
- `TaskMeta`'s status select offered five statuses, so **cancelling a task was
  unreachable from the entire UI**. Fixed here since the drag deliberately never
  resolves to `cancelled`.
- `BOARD_COLUMNS` and `STATUSES` were byte-identical declarations of one
  vocabulary. Collapsed.
- The browser harness's stubs are shape-sensitive in ways that fail as a blank
  page: `/members` is `{ members }` not a page, `/tags` is `{ tags }`. Three
  probes to find it. **The token guard also reads CSS comments** — `var(--n)`
  inside a comment failed it.
