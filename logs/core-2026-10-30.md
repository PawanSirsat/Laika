**Decisions**
- Mounted on `/handoff-offers` instead of `/me/...`, beside approve/accept, so
  `app.ts` is unchanged.
- No new §3.2 action. The read asks `project.read` for each project. The
  approver rule asks `task.handoff.approve` for each project twice: once
  with no owner (does the caller lead the project?) and once with the
  caller as owner (may they approve tasks assigned to them?). SQL then adds
  the assignee test. So the rule stays in `can()` and pages stay exact.
- Work requests are left out: the agent answers them, not the person, and
  counting them would inflate the badge.
- An unnamed recovery is not in `needs_approval`: it is not cross-owner. It
  shows in `recovery` with `next_action: name_receiver` for whoever may approve.
- Renamed the filter type `PersonInboxView` → `PersonInboxFilter`: the
  census reads every `*View` as a response type.
