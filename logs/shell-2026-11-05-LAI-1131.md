**Decisions**
- lowlight over Shiki: Shiki's default engine is WASM (blocked by `script-src 'self'`), and its css-variables theme puts a style attribute on every token. Classes map onto existing tokens through `var()` aliases, so `theme.css` stays untouched while the appearance PRs are open.
- Mermaid is pre-rendered rather than run: the spike measured 24 `style-src-elem` violations for 4 diagrams × 2 themes under the real policy, and none for `script-src`. The policy is not relaxed. SVGs ship as `<img>`, with a labelled source fallback for any diagram with no current picture.
- The renderer is a sibling of TaskMarkdown, with the same three safety rules, rather than an edit to it. Folding it in is a Phase D call.
- The CSP browser test builds the header with the server's own `buildContentSecurityPolicy`, loaded by path (server/src is outside the web rootDir), rather than copying the string.
- Outline tracking uses a full-viewport IntersectionObserver plus a once-a-frame scroll check. A narrow observer band missed jumps, which the test caught.
