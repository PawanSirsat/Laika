**Decisions**
- *Connected* = `agent.last_seen_at` within 15 min. That stamp moves only on
  a request authenticated as that agent, so it is real evidence; a token
  stamp is never read. *Ready* is never produced (needs slice C verification).
- Imported confirm reuses `POST /agents/devices/confirm` (the classic
  *This is mine*). It exists, so the action ships here, not later.
- *Working on LAIKA-n* is **not shown**: no existing API gives an owner an
  agent's live claims (`GET /agents/:id` has sessions, not claims).
- Disconnect tool reads `GET /agents/:id` first and names the credential
  prefix and each running session; if that read fails the dialog says the
  sessions could not be read, never "none". Disconnect device lists every
  active tool with its running-session count and calls
  `POST /agents/devices/revoke`.
- Rename is offered only on conflict rows (the classic rule, D-120 note).
- Add device / Add tool push `?add=device|tool` and render the classic
  wizard alone (`wizardOnly`); D4 replaces it. Said in code, not copy.
- Version: every active row shows *Version unknown* (no client reports yet).
