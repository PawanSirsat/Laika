**Discovered**
- `LAIKA_PUBLIC_URL` cannot be unset in production: `docker/entrypoint.sh` and
  `readEnv` both refuse to boot without it, `server/src/index.ts` passes it to
  the pairing routes, and `docker/aws/laika-ec2.yaml` writes it into
  `/opt/laika/.env` (read by `host-restart.sh`'s `--env-file`). So
  `public_url_unset` is reachable only from a non-production `createApp`. The
  value is the instance's public IP read at first boot; whether it equals the
  Elastic IP was not checked (no read of the host in this task).
