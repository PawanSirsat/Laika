  Inbox tabs still add up to the sidebar's badge (LAI-796's rule); the plan did
  not name the tab count.

  unmount the row under the reader's focus (same reason `HandoffsTab` holds rows).

  restore target, wherever `s` was pressed from — the first run restored focus
  to Accept because `event.target` was Accept.

  both Markdown docs wholesale**; they were restored from `HEAD` and the five
