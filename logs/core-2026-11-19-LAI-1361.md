**Decisions**
- Files ride on `GET /unlisted` only, as a new `UnlistedEntryView`. The alternative was `UnlistedView` everywhere, which would also have changed `log_unlisted_work`'s MCP answer and promote's.
- The list gates with the content route's own function, rather than a copy of its checks, so it can never name a file whose link 404s.
- Bare `pass`/`token` columns need letters and digits, 8+: a test report's counts and a word list's words pass, and `hunter22`/`abc123def456` do not. A purely alphabetic password in such a column is still missed.
- A plain top-level zip is now opened, not only nested ones. Before this it passed unread as binary, which is the same hole one level up.
- `.pptx` is read with the Word reader: DrawingML's local names (`p`, `t`, `br`, `tbl`, `tr`, `tc`) are the same.
