**Decisions**
- Removed the availability tooltip rather than move it: above would cover the
  app header, beside would cover the figure; the control's own words carry
  everything the tooltip said.
- Shading: only the person's own working hours (My availability's working
  week, an existing API), and only with a key; nothing without them. The real
  Timeline's sun/future shading is unchanged.
- One primary Start timer: the toolbar's, accented on an empty today; the
  card keeps *Add time*. Past/draft-off/future cards are unchanged.
- No total vs target: the API has none (LAI-1215 checked); none invented.
- Tools: grouped as one labelled cluster rather than folded into a menu —
  each has its own panel already, and a menu would add a click to all four.
- Week, Month and Year already had one row (‹ Today ›, trail, View, zoom);
  they now share `data-nav-row` and were checked at 1440/390 in both themes.
- Mutations, one per behaviour, each seen red: availability tooltip put back,
  Confirm day shown with no drafts, group role removed, nav row stacked,
  week total hidden, now line dropped, working hours dropped, message
  floated, timer not primary, phone note back to a head button. A
  keyboard-focus variant of the tooltip test stayed green with the tooltip
  put back, so it proved nothing and was dropped (filed LAI-1224).
