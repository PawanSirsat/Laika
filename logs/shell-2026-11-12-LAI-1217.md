**Decisions**
- Someone else's setup never links to `/developer`: it is the reader's own
  page, so an owner would land on their own setup. The admin step is an
  in-tab jump. This is decided by `voice.own`, never by inference, and the
  revokes stay on the server's `can_revoke`.
- Token flags are advisory. They do not change the headline count or the
  tab's *N to fix* badge (`toFixCount`), so the tab and Developer access
  still agree on what needs attention. They get their own summary line and
  feed the own view's last-resort next step.
- *Never used* is already the token's status word, so the row does not
  repeat it as a chip. It is still counted.

**Discovered**
- A zsh `for p in "a b"; do set -- $p` does not word-split, so a screenshot
  loop ran with an empty theme and a NaN width, and one run hung. It was
  stopped and re-run explicitly, one width and theme per process.
- The 390 two-column tile rule was redundant: the base `auto-fit
  minmax(9rem)` grid already gives two columns at that width. Its mutation
  survived, so the rule was removed rather than credited.

No port was used (browser harness only). No Laika board tools were used in
this session.
