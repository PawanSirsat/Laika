**Decisions**
- The poller is a framework-free controller with an injected environment, the
  hook a thin wrapper — this package has no renderer, so the timing rules are
  only unit-testable outside React (the `query-cache.ts` pattern).
- Unlisted now polls (30 s) — it never re-read before, so "keep rows on a failed
  re-read" had nothing to apply to; the task names `usePolled` for it.
- `key` option restarts from loading — the old answer to a different filter is
  not stale data for the new one.
- Only the newest read's answer is applied rather than aborting the older one —
  aborting a GET joined in `query-cache.ts` would cancel it for other callers.
- One space to choose from is preselected; a slug not in the offered list is
  never sent.
- Disabled *Create task* gets a scoped disabled look in unlisted.css — the
  shared `.bar-control` has none, and changing it is outside this task.
