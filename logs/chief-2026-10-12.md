**Decisions**
- Monograms for every agent rather than vendored logos. REPORT §Logos says Anthropic, OpenAI, Google and Microsoft forbid their marks without permission, and the rest need permission or are unclear. NOTICE.md records why.
- The minted token's `last_mcp_at` proves the connection, not presence. Presence is still the fallback when nothing was minted on the page, and the page says it is the weaker check.
- Config blocks are typed `none`/`secret`/`inline`, and a test enforces that a `none` block never contains the token. Inline configs exist only for clients that cannot read an env var: Antigravity, Zed, Junie, Warp, and the bridge for Kiro, Claude Desktop, JetBrains AI Assistant and Any MCP client.
- `laika connect` appends one marked rc block that sources ~/.laika/env with `set -a`, so env-referencing configs can see LAIKA_TOKEN. The alternative, inlining the token everywhere, would put it in files that get committed.
- The CLI half was built by a sub-agent in this worktree with no commits. I reviewed it and committed it.
