**Discovered**

**My first assertion failed against correct code.** I asserted **0** readline
listeners at raw-mode entry, from a probe on a bare `PassThrough` where
`close()` does leave 0. It leaves **1** in the real harness. So I measured both
sides through the actual code before rewriting it:

```
           while open   at askSecret's setRawMode(true)
close()    2            1     <- let go
pause()    2            2     <- did not
```

The assertion is now *"fewer than while open"*. **The number was never the
property** — "the readline let go before raw mode was set" is.

**Substituting `process.stdin` works once per process.** The first `prompt.ts`
instance sees the fake; a second does not, however the module is cache-busted,
and `askSecret` then never settles. Measured outside `node:test` too, so it is
the substitution and not the runner. **Stated in the file rather than worked
around**, and the single scenario runs in the order `init` actually uses.

and **green for the pre-existing suite** — which is precisely the gap LAI-441 was
filed on.
