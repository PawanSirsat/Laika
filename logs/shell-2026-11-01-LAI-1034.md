## 2026-11-01T18:45:00Z — LAI-1034 review round 2 (PR #191)

**Changed**: `cli/src/agent-git-home.ts`, `cli/test/agent-git-home.test.ts`, `cli/README.md`.

**B2, fixed**: `gitHomeConfig` now builds the text itself (values always
double-quoted, with `\` `"` newline and tab escaped; subsection `\` and `"`
escaped). It writes the includes, an initial reset per section, then every
live entry, resets included, in git's read order, opening a new header for
each run of one section. `git config --add` had appended to the section's
existing block, which grouped alternating sections.

**Found while fixing**: Apple's git reads a built-in config (scope `unknown`,
`/Library/Developer/CommandLineTools/usr/share/git-core/gitconfig`) with
`credential.helper=osxkeychain` before the global files. A per-file global
read would never see it, and the initial reset would drop it under polly-home.
So helpers are now read in one call, `git config --show-scope --includes -z
--get-regexp`, from `/` with HOME set to the person's. Scopes kept: system,
unknown, global. That gives git's own cross-file order. An absolute
`$XDG_CONFIG_HOME` is honoured, the optional item.

**Verified**: 6 shapes run real `git credential fill` with name-logging stubs,
