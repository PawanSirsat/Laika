**Decisions**
- **Did it while both builders were idle rather than waiting for a formal

  rewritten ancestors. The window was now.

  reset author *dates* too, flattening the real timeline into one minute.
  `--env-filter` changes only the email, so timestamps and ordering survive.

  `refs/original` as it created it, destroying the safety net in the same pass.
- **Deleted my own backup tags.** `--tag-name-filter cat` rewrote them along with
  everything else, so they pointed at post-rewrite commits — a backup that
  isn't one, and it would have been pushed to GitHub as noise. `refs/original`

  SHAs are identical and both builder worktrees came out clean without a single
  file changing.

  commit metadata moved — the trees they had checked out were byte-identical. Had
  this rewrite touched content, both builders would have woken to a detached or
  dirty worktree. Worth remembering before any future rewrite: **this one was
  safe because it changed no bytes**, not because rewrites are safe.
