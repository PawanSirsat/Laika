**Decisions**
- **Deactivation by an agent token is refused as a whole** if any task it
  would move sits in an agents-off space, and nothing changes. The alternative
  was to skip those tasks, which would leave work assigned to a deactivated
  person, the exact thing offboarding exists to prevent.
- **A heartbeat skips only the task write; it does not refuse.** The beat is
  presence, and the token's own. Refusing it would break time tracking for a
  space that only asked agents not to change its tasks.
- **The rule is asked alone, not as `can(task.write)`.** Asking the full
  check would also add a role check that offboarding (whose authority is the
  org's) and heartbeats never had.
