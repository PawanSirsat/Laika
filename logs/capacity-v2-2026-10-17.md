**Decisions**
- Last seen reads a session's `created_at` (a sign-in), not `updated_at`:
  better-auth slides `updated_at` daily on any request, and the shell's count
  polls run from every open tab, so it would mark a sleeping person online.
- Presence off hides last seen as well as status — the activity log must not
  answer what the org chose not to record. Workload stays.
- `profile_kind` and the agents a person uses but is not running are
  owner/admin only (D-078, D-076 item 5); both admin-only fields are session
  only, so a token never gets them.
- Load is a fixed server rule: none / light (≤2 in progress, ≤5 open) /
  normal / heavy (>5 in progress, any overdue, or >15 open).
- Native selects are forbidden (LAI-726): the space and sort controls use
  `Dropdown`. An Overdue chip was added so the Overdue tile has a filter.
- Tasks are read only for a matched session task and an opened *Show tasks*;
  LAI-728 stays its own task.
