**Decisions**
- Each shard runs the package's own `test` script, so typecheck and the
  glob stay single-sourced and `test-runner.test.ts` still guards what CI
  runs. Node takes options only before the glob, so the web shard goes in
  through `NODE_OPTIONS` (checked locally on a 4-file toy suite: 1/2 ran
  files 1 and 3).
- `if: always()` on the aggregate: without it a failed shard leaves the
  aggregate skipped, and a skipped check reads as passing.
- master has no branch protection or rulesets (`gh api` 404 / `[]`), so the
  only consumer of the check is `deploy`'s `needs:`.
