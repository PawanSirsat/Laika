**Decisions**
- References match relative or on **any** origin, not only `LAIKA_PUBLIC_URL`'s — Ksage serves one deployment at two origins, and threading the public URL into every task and comment writer (REST, MCP, meeting review) would have been invasive for a check the id and project already make safe.
- A deleted comment keeps a file the task's text or another live comment still embeds — the task file's sentence would have removed a description's file the moment it was also quoted in a comment; D-150 item 6 says *only it carries*.
- `attachment.removed` only for a file that was `ready` on a task — a pending upload that named its task never wrote `attachment.added`, so a pair is always a pair.
- All routes, list included, answer `503 attachments_off` when off, as D-150 item 1 says, rather than the list answering an empty set.
- `OrgView.attachments` is always present (`null` when off), readable by everyone, unlike `ai`'s absent-not-null: whoever may attach needs the limit before choosing a file.
- The sweep processes at most 500 rows per case per run and skips a row whose object the store would not delete, so a down store costs an hour, not the run.
