**Decisions**
- **The wizard parts keep Connect's `conn-*` classes, and their rules stay in
  `connect.css`.** Those rules are spread through the file (`.conn-block-label`
  is defined three times, `.conn-agent` twice), so moving them would reorder
  the cascade, and "no behaviour change" is then a guess. Keeping the classes
  keeps the markup byte-identical, which the golden proves. A V3 screen that
  uses the parts imports `connect.css`, as ProjectsTab already does. Moving the
  rules into a component stylesheet is for slice F5, when the classic page goes.
- StatusChip and OverflowMenu are new and have their own stylesheets. They use
  existing tokens only (`--chip-*`, `--overdue`, `--blocked-bg`, `--accent`,
  `--bg-card*`, `--border-default`, `--shadow-modal`); no new token, no raw hex.
- Nothing on Connect uses the menu or the compact chip yet, so they are shown
  on `/design/states` in their own lazy chunk (like the agent states) and
  tested there.
- The menu's arrow wrap reuses `trapTarget` from `use-dialog-focus.ts`.
  `useDialogFocus` itself is not used, because a menu must let Tab leave
  rather than trap it.
- ToolTile is generic (`id`, `name`, `client`, `beta`, `group`), and the
  picker's tiles still come from `AGENT_GUIDES` / `groupedAgents`. No count was
  added.

## 2026-11-02T02:55:00+05:30 — LAI-1044, CI round 1

**What happened.** PR #201's first CI run failed `Gate · web 4/4` in
`connect-golden.test.ts`. Steps 1–2 passed. Steps 3–4 (5 scenarios) failed on
**light computed styles** while their markup and aria tree matched.

**Cause.** `.conn-line` pads by `calc((var(--lead) + 2) * 1ch)`. `1ch` is the
mono font's glyph width, so the computed px differ between macOS and the
Linux runner even though the rule is the same. I had excluded geometry because
it depends on fonts, and missed that one spacing value is font-sized too.

**Fix.** That element's `padding` is now recorded in `ch`, measured against a
probe in its own font, to one decimal (the probe reads 2.003ch for 2ch on
macOS). The golden was regenerated **from the pre-extraction source**
(`35ad1314`, in a temporary worktree `.polly/wt-1044-base`, removed after). The
golden diff is exactly the 5 step 3–4 scenarios × {light, dark} style
digests; no markup or aria entry moved. The refactored page then matched
again, 9/9.
