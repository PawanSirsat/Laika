  different loader then again there lot more unnecessary loader."* Measured

  missing; this removes feedback that was never needed, and it is the same job.

  one — any route may be behind it — so it has no business drawing a card
  layout that the board then replaces with a different shape.

  a spinner beside a usable board reads as *stuck*, not *coming*.

  reversed the one-colour rule (LAI-606 gives In-progress and Done their own
  badges), so an assertion that the count never varies would block the correct
