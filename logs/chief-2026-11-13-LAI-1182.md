**Decisions**
- Two facts inside the Workspace settings card rather than a separate card —
  the task places them beside Time and Breaks, and the card's `dl` already
  collapses to one column at phone width.
- The password is cleared from the form on every outcome, and the field is
  `autocomplete="new-password"` so the browser never offers the owner's saved
  Laika password for the Clan account.
- Holidays absent when its read fails (as Time and Breaks are); the HR fact
  shows its read failure, because only its holder sees it and a silent miss
  would read as "not connected".
- The harness's default grants were left without `org.hr.configure`: adding
  it would draw the HR fact (and a 404 for `/org/hr`) into every other owner
  test on Overview. The new test file passes the action itself.
- A sentinel value for *Not on Laika* in the picker, distinct from the empty
  "Choose a member" of an unmatched row, so an untouched row sends nothing.
