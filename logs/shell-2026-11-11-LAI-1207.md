**What changed**
- `server/web/src/components/EmptyPanel.tsx` (new): neutral empty state with
  four variants — `first-use`, `filtered` (its action is always *Clear
  filters*), `no-permission` (quiet: "not yours to add"), `caught-up`. Title,

  `EmptyState` props). No role, no live region.

  client's "Request failed with status N." stand-in). `forbidden` still routes

  so focus stays and the label never changes (LAI-293's rule).

  block stops the region fade, button transitions and press scale.

  stroke as the existing three.
- `StateGallery.tsx`: lazy-loads `StateKitGallery.tsx` — twelve specimens,

**Decisions**
- New files instead of polishing `EmptyState.tsx` / `states.css` in place —
  #280 edits both and the brief forbids editing files those PRs own. The kit
  reuses `states.css`'s `.skeleton` pulse and `.spinner` rather than forking.
- `StaleBanner` takes #280's prop names (`readAt`, `onRetry`) plus #320's
  (`what`, `error`, `retrying`); #320 adopts by renaming `loadedAt` → `readAt`.
  `role="status"` as #280 has it, not #320's `alert`: the rows still work.
- Error tone: the warning colour is on the glyph tile only; title and why
  stay in text colours, Retry is the ordinary primary button. LAI-020's red
  headline made a timeout read like data loss.
- Skeleton delay 300 ms (not `useDelayed`'s 150) and no hold: these stand in
  for whole regions, and the caller swaps content in the moment loading ends.
- Members' empty state has no button of its own — "Add member" is already
  above it, and two identically named buttons is a strict-mode trap.
