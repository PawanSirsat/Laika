**Discovered**

**Decisions**
- *A viewer gets no scope control at all, with a sentence saying why.* The
  server **forces** rather than refuses, so an offered choice would not error —
  it would mint something other than what was asked for. A test asserts
  `mayChooseScope` and `forcedTokenScope` agree, so nobody can be offered a
  choice the server overrides.
- *A revoked token stays on the list, dimmed, with its date.* Removing it would
  hide that it ever existed.
- *`/tokens` earns its nav entry now the screen exists* — the LAI-082 rule
  working rather than an exception to it.

**Discovered**
- *The once-only secret was not once-only.* Dismissing removed it from the DOM,
  `innerText` and both storages — and **left it in React state**, at hook 9, as
  `{ token, secret }`. React double-buffers: a hook's previous value stays
  reachable until another render replaces it. Fixed by blanking **through**
  state — `{ token, secret: '' }` and only then `undefined` — so the retained
  render holds an empty string.
- *A probe that looked at nothing reported "clean", and I nearly believed it.*
  My second scan walked `root.current`, but the `__reactContainer` key **is**
  the root fibre, so `.current` was `undefined` and it scanned zero fibres. It
  returned an empty result that looked like a pass. Caught only because probes
  one and three disagreed with it. **Confirming a negative requires proving the
  probe can see a positive** — the final version asserts it finds the secret
  while one is on screen (148 fibres) before asserting it cannot afterwards.
  This is the same family as the console-vs-server-log confusion on LAI-411 and
  the `grep` on the design file yesterday, and it is now three for three.
- *Four prefix characters are enough.* CHIEF asked me to stop and say if not.
  Four tokens on one account gave `Qb5L`, `Nyc2`, `iRMK`, `Zg0D` — distinct and
  distinguishable at a glance, with the name doing the real identifying. SPEC
  §4.9 needs no amendment; reported rather than worked around.

**Verification**
- 545 web, 1349 server, typecheck, lint, `format` clean.
- Browser, both themes: viewer sees no scope control and gets a forced
  `read_only` token; owner sees two; secret shown once and gone from DOM, text,
