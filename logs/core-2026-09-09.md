gap. LAI-163's own words are *"a guard whose reach is decided by something
nobody is checking"*, and the something was a regex I had written forty lines

`fieldsIn`, so the two halves of this file cannot disagree about what a row *is*.
24 → 29 statements. A test names those five columns so it cannot regress
quietly. **The general form: when a file already parses the artefact, a second
parser of the same artefact is a bug with a delay on it** — and the delay is
however long until the document uses a shape only one of them handles.
