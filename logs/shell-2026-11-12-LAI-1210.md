**Decisions**
- No Security figure on Overview: an "active tokens" count needs every
  person's tokens read one by one; a link row is honest, a tile would be a
  number-shaped label (first draft had one; removed after looking at it).
- Prefix → group name map in `permissions-view.ts` for today's §3 prefixes,
  falling back to the prefix itself, so a new area is grouped, never dropped.
- Status badges say "secret set" / "configured", not "connected": the client
  cannot tell whether GitHub actually delivers.
- Activity fixture rows are pinned to local calendar days so the day groups
  do not depend on when the suite runs.
