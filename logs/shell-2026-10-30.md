**Decisions**
- "Delivered to" is not built. No REST endpoint returns §4.69's deliveries;
  §5.1 forbids stubbing it or adding it from a UI task. It was raised on the
  card for CHIEF to file, because CHIEF's LAI-500 – LAI-599 block is full and
  no task file could be numbered.
- An agent is named only when it is the reader's own (`GET /agents` answers
  nobody else's); another person's agent reads "through an agent".
- "Save mine over rN" is an explicit overwrite after a confirmation, not a
  merge: merging is out of scope ("editing semantics beyond optimistic
  write").
