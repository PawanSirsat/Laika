**Decisions.**
- **The slim-list fix waits for the drawer, not for the fonts.** The task
  named the fonts. The measurements said otherwise:
  - `page.goto` already waits for the faces in use. Holding the woff2 files
    for 6 s made the test take 7.7 s instead of 1.6 s. At the first
    measurement, both faces in use (Plus Jakarta Sans, JetBrains Mono) read
    `loaded`.
  - Only `y` moved on CI, which is a transform rather than text reflowing.
    The drawer opens 12px low (`drawer-slidein`, 280ms,
    `cubic-bezier(0.32, 0.72, 0, 1)`), and the pulse shows at 150ms. The
    curve is 0.87px short of rest at about 118ms in.
  - With the CDP animation clock at 0.5× and the read landing 600ms later:
    without the wait, `y 133.559 → 132.406` (red, CI's shape); with
    `document.fonts.ready` only, `y 133.566 → 132.406` (still red); with the
    drawer wait, `132.406 → 132.406` (green).
  - So a fonts wait would have been a no-op, under a comment claiming a cause
    it does not have.

**Discovered.**
- **`SvAMs7oo…` is `fallback.html`'s real `<style>`, not a comment.**
  - `app.ts` always hashes `staticOptions.fallbackDocument`, which is
    `static/fallback.html` (lines 8–84), and never `public/index.html`.
  - `server/web/index.html` and the built `public/index.html` contain no
    `</style>`, so they gave `[]` before this change too.
  - The server's CSP for the built SPA therefore still carries the fallback's
    hash, and it still differs from nginx's by exactly that hash:
    `style-src-elem 'self' 'sha256-SvAMs7ooQNphe1Tc5XfBY/P1X9abH8eLukft4pFWmDE='`
    against `style-src-elem 'self'`.
  - The web-serve guard does not see this. It holds nginx to
    `buildContentSecurityPolicy([])`, not to the CSP the server really sends.
  - Making the two equal means not hashing the fallback when a build exists.
    That is a CSP behaviour change in CORE's code, left for CHIEF. The
    criterion's equality clause is not met.
- **The task file's run list was partly wrong.**

  - `gh run view <id> --log-failed` shows only the latest attempt. Earlier
