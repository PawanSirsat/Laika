**Decisions**
- `plugin/commands/README` ships **without** a `.md` extension. Every `.md` under `commands/` registers as a slash command, so the obvious `README.md` shipped a junk `/laika:README` to every user with no frontmatter and therefore no `allowed-tools` constraint. Dropping the extension keeps the README the criterion asks for and removes the command. `hooks/` and `skills/` keep `.md` — verified inert there.
- The command is `/laika:status`, not the criterion's literal `/laika-status`. Claude Code namespaces plugin commands as `/<plugin>:<file>`; the only way to the hyphenated string is renaming the plugin or shipping `/laika:laika-status`. SPEC §5 says `/laika:status`, so the spec won over the criterion's shorthand. Flagged in the task file for PM.
- The status script reports the token's `lai_` prefix and character count rather than a masked excerpt. Both are format facts, not secret material, and they are what actually diagnoses a truncated paste; any excerpt of the value is worth stealing and none of it is worth showing.
- Declared `hooks`, `commands`, and `mcpServers` in the manifest even though all three are the loader's defaults — the criterion asks for declared components, and an explicit manifest is what a reader checks first.
- `hooks/hooks.json` exists but is empty rather than absent. A manifest `hooks` field pointing at a missing file is a validation risk; an empty one costs nothing and documents the seam.

**Discovered**
- `commands/README.md` really does become a command. My first probe — asking a loaded session to list `/laika` commands — reported only `/laika:status` and I briefly believed the directory ignored non-command `.md` files. `claude plugin validate` disagreed ("Validating command: .../commands/README.md"), and invoking `/laika:README` settled it: `${CLAUDE_PLUGIN_ROOT}` expanded in the output, which only the command pipeline does. **Model-mediated inventory probes are not evidence; `claude plugin validate` and direct invocation are.** Cost ~15 minutes and one wrong statement to the operator.
