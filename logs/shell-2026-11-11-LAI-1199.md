**Decisions**
- Key resolution on the client (project list → prefix or former prefix → the
  space's shared task set) — rejected adding a server key lookup: not mine, and
  the shared set is already held by most views, so it usually costs nothing.
- *Back to …* steps back with `history.back()` only when the drawer's Expand
  remembered this key (module state, no storage); a pasted link navigates to
  the task in its board — rejected `?from=` in the URL, which leaks into links.
- Focus key `.` — checked against `/`, `c`, the Review dialog's j/k/a/s and ⌘K;
  ignored while typing, in a combobox, with a modifier, or under a dialog.
- Below 1024 the page is one column with a tablist (switching replaces), not a
  scrolling column: on a phone a five-section page as one scroll is the trap.
- Reused `TaskMeta` for status, assignee and agent rather than rebuilding them;
  sprint is read-only there because its write is still inside the panel.
