**Decisions**
- Pulse is its own component and request. A failed read is a line with a retry, and
  the rest of Overview still reads. Same `.org-stat` tile; `.org-pulse` lets the five
  sit in one row wide and two to a row at 390px.
- Membership wording: "added Mia as Member", "changed Adam's role: Space admin → Member",
  "removed Mia (Viewer)". When `via` is join or invite, the row reads "joined as …".
  Leave reads "left the space as …". An org-scoped row says "Admin → Viewer", and an org
  `member.added` reads "joined the organisation as …". A row with no `user_name`
  (written before LAI-993) keeps the generic line.
- Export CSV is a plain `<a download>` to `/api/v1/activity/history?format=csv&<filters>`,
  sent with the session cookie, never with `limit` or `cursor`. It sits on the
  Activity tab, which is already gated by the server's `audit_log.export`.
- Pins are kept in `localStorage` under `laika.pinned-spaces`, a key separate from
  recents, so a pin never costs a recent slot. Pinned rows come first in creation order,
  then three recents. A hairline separates the two groups. The pin control sits beside
  the link, not inside it, so a row's text is still its letter and name. Spaces can be
  pinned from the More-spaces popover too.
- The grants fixture now carries descriptions, because the server always sends them.
