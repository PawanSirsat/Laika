  the rest of Overview still reads. Same `.org-stat` tile; `.org-pulse` lets the five

  recents, so a pin never costs a recent slot. Pinned rows come first in creation order,
  then three recents. A hairline separates the two groups. The pin control sits beside
  the link, not inside it, so a row's text is still its letter and name. Spaces can be
  pinned from the More-spaces popover too.
- The grants fixture now carries descriptions, because the server always sends them.
