**Decisions**
- The accent pick lives in the shared block as `--accent-source: var(--brand-periwinkle)` and each theme's `--accent` reads it — one line reverts every theme, where a per-block hex would have been two edits that could disagree. `--accent-bg`/`--accent-border` are `color-mix` of `--accent` so they follow a revert. Because `--accent` is no longer a hex, the AA pairs check both candidates (`--brand-periwinkle`, `--brand-legacy-purple`) at source.
- Status blue moved to sky (#38bdf8 dark, #0369a1 light): the prototype's #5b8cff is within a few degrees of hue of the periwinkle accent, and "status is never the accent" (LAI-605) is a rule about being told apart, not just about token names.
- The splash's CSS is imported from `index.css`, not just from the components: with only the component imports it would still land in the entry CSS today, but nothing would say why, and a lazy route split would quietly break the pre-JS splash.
- SessionGate keeps the LAI-608 delay. The brief said to use the splash there; the owner said in LAI-608 that a fast instance should show nothing. Both hold: nothing for 150ms, the splash after.
- BrandSpinner went where the shape of what is coming is genuinely unknown (Developer access deciding classic vs V3), not over any skeleton. There is no `LoadingState` "page" shape in this tree.
- Wordmark is round-capped strokes, not outlined glyphs: one stroke width gives the bold geometric weight, and it stays a dozen numbers that a test can compare.
- The header's `Brand` stays on public routes without a card (`/design/*`), so the LAI-062 AC4 rule — a signed-out page still names itself — holds.
