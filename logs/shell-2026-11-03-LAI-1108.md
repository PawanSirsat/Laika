**Decisions**

- (b) A **positive** list of permanent phrases, the opposite of LAI-1107's
  choice for transient ones: here a phrase missed is merely retried (the old
  behaviour), never wrongly dropped. Measured: `Could not read from remote
  repository` follows an SSH host that did not resolve as well as a missing
  repository, and a missing local path says `does not appear to be a git
  repository` — both stay transient. HTTP 401/403/404 are in; a 5xx is not.
- (a) Both checks, not either: the real-path check alone passes another
  clone moved (not linked) to the path, and the common-dir check alone
  passes a symlink to the same worktree moved away. Each has its own test,
  and each mutation turned only its own test red. The common dir is compared
  with the **configured** checkout, not the record's `repo_dir`, which could
  be rewritten with the rest of the record.
- (c) Cleared in one place, `decided()`, used by every handled path —
  rather than at each refusal — so a later handled path cannot forget it.
  The bound is from the entry's retry time, not its creation, so an offer
  still retried at the 15-minute cap is never forgotten between two tries.
- (e) The config env is injected (`ConfigEnv`), defaulting to the hook's
  own in `hookCredential`, so unit tests never read this machine's process
  table — on Belka that would find the real Omnigent `claude`.
- (f) "The run" is the marker's verdict, so Codex's is read from its
  process like everything else. `unknown` counts as not-Omnigent: a session
  recorded as an Omnigent run that cannot be told now is decided again, and
  a hook whose MCP follows then opens no session (fail closed).
- (g) The list's texts are literals, not `headersHelper(…)` calls, so an
  edit to the function cannot change them. Today the list holds one text
  per harness, equal to the current helper, so "no list" and "list" behave
  the same until the helper is edited. The mutations therefore simulate that
  edit: g1 (old matcher + an edited helper) strands a device holding
  LAI-1101's helper, red; g2 (the list + an edited helper) leaves that
  device recognised and reddens only "the current helper is in the list".
- (h) `tool add` only, as the finding named. The other readers and writers
  of the same files are LAI-1110.
