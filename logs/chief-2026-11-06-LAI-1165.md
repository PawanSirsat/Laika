(`time-member-entries.ts`) so it can read `closedThrough` from
`time-solidtime.ts` without a cycle; `time-entries.ts` exposes
`newEntryFields`, `patchEntry` and `revisionsOf` so own and member writes
share one validator and one revision writer. By role (`isAdminUp`), not a
grant, as `time_sync.import_all` is. Self is `422 use_own_time` (as
`use_developer_access`), and the role is asked before the user is looked up so
a member gets the same 403 for any id. Closed period is enforced on this path
only — the own path never checked it, and changing that is not this task. The
notice subject is a machine-readable snapshot the client words, so no wording
lives on the server. Revisions gained `changed_by_name` on both the own and
member reads (client type mirrored, drift test green). On the client the
Timeline gets `readOnly={!canEdit}` plus `lockDrafts`; the tray, the header
buttons, the timer and the phone timeline stay read-only for someone else's
day. `ADMIN_UP_ORG` in the browser harness gained the action, as
`/permissions` serves it to both.
