**Decisions.** The owner: imports are editable by owners and admins on someone
else's time, because nearly all production time is imports. The person's own
path is unchanged and still refuses an import. **The sync path needs no change**:
an import is linked by `solidtime_entries.entry_id` and goes down the twin
branch of `reconcile` — an unchanged hash leaves the edit, a changed one
re-syncs the Solidtime version over it (`syncEntry` also revives a deleted
one) and counts a conflict, and a delete in Solidtime calls `retireEntry`,
which returns early on an entry already deleted. `solidtimeOutbox` never
pushes an import, so the edit stays in Laika. On the client an editor gets the
Inspector controls and Timeline drags for an import on someone else's day; on
your own day imports stay locked. An import's first revision names nobody
(Solidtime made it); later ones name whoever changed it.
