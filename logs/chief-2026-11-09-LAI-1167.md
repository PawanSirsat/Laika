**Decisions.**
- The provider lives in `SpaceFrame`, not the board: every view's bar has
  *+ Create*, and the dialog must open from the Calendar as from the List.
  `SpaceFrame` was split into the data half and a `SpaceFrameBody` under the
  provider, because the bar's `onCreate` needs the context the same component
  renders.
- The embedded editor reports Escape through `onEscape` rather than letting it
  bubble. ProseMirror's `captureKeyDown` `preventDefault`s every Escape and
  Enter, so the dialog's "respect a consumed Escape" rule (the one that lets an
  open menu keep it) would otherwise swallow the editor's. Discovered when the
  first browser run left the dialog open after Escape in the document.
- The embedded editor also skips `placeCaret` on mount: it focused the
  document when the chunk arrived and took focus off the Title a moment after
  the dialog opened.
- *Create another* focuses the Title from an effect keyed on the editor
  remount, not inline after the create: the input is still `disabled` by
  `busy` until that render commits, and `.focus()` on a disabled input does
  nothing.
- Sprint drawn disabled rather than hidden while loading (a small, stated
  deviation from the plan) so the two-column grid does not jump. It first said
  *Loading…* in its placeholder; CI round 1 below took that out.
- `Chosen blockers` names the chip list, not *Blocked by*, so a label query for
  the control does not also match the list once a blocker is added.

**Discoveries.**
- `.rich-editor` fades its background over `--transition` (120 ms). A
  screenshot or a computed-style probe taken at once after `setTheme` reads
  the box half-way between the themes — white in dark. Not a defect; the shot
  waits 300 ms. Worth remembering for any theme screenshot of the editor.
- The bar's search box is drawn only on a view that does not claim the filters
  (`useSpaceFiltersClaimed`): neither the board nor the List has it. The
  "`c` typed in the search is a letter" case runs on the Calendar.
- Playwright `has:` with an inner locator already scoped to the dialog never
  resolves inside a `.field` (the inner locator is relative to the outer
  element); use `page.getByLabel` inside `has:`.
- zsh does not word-split `$FILES`; a space-joined list reads as one path to
  eslint and prettier. Pipe `git ls-files -m -o --exclude-standard` into
  `xargs` instead.
