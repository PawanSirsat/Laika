**Decisions**
- **Sidebar footer: nothing stays.** The person menu (profile, theme,
  Appearance, Developer access, sign out) is the top bar's avatar; a second
  one would be two doors to one room. The org name moved with the brand into
  the top bar's lockup.
- **Title rule (updated):** the top bar names no page. Each page names itself
  once in its own `h1`; a space's views add *Spaces /* (→ /projects) above
  the space's title row; a member profile keeps its *People / name* trail in
  the page. On phones the space breadcrumb is not drawn (content stays high;
  space-header's budget moved from ~15% to ~20% of 844px — the title row
  itself left the 48px bar, the reason is in the test).
- **Viewing chip:** in the top bar, at the start of the right cluster, beside
  the search/Create group — the same component, still gated on
  `people.analytics.read`.
- **Create unavailable:** stays drawn, `aria-disabled`, reason in the tooltip
  and in hidden text ("No space lets you create a task"; "Checking where you
  can create…" before `/permissions` lands), rather than vanishing as LAI-1221
  did.
- **Space defaults:** opener's space (lane, `c`, `?new=task&project=`) → the
  space on screen if creatable → `laika.create.space` (written on a
  successful create) if still creatable → first allowed. Allowed = the
  server's per-space `task.create` via `useGates`, never a role.
- **Space change:** keeps title, text, priority, dates, labels, effort,
  deliverables, outside id; clears status (→ new default), sprint, agent,
  parent, blockers; assignee dropped only if not among the new members.
  Create waits for the new space's statuses, members and sprints (each read
  aborted on change) — no stale submit.
- **Lane +:** opens the dialog (the brief's instruction) rather than the
  inline composer; the composer is now unreachable → LAI-1229 to remove it
  after the owner confirms.
- **A page that changes space under the open dialog closes it** (kept from
  LAI-1167's review): the column it opened with was that page's.
- **Person avatar has no tooltip:** one raised as the menu hands focus back
  sat over the bar's popovers (caught by my-day-body-ux).
- Phone (390): menu, mark, search icon, +, bell, avatar; ? and settings fold
