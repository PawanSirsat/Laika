**Decisions**

- Route tabs (`PageTabs`, `ViewTabs`, profile) stay a `nav` of links with
  `aria-current`. They take every behaviour from the strip, but not
  `aria-selected` or `aria-controls`. The design-system proposal settles this
  ("they navigate"), and naming a panel would mean reshaping five screens,
  Organisation among them. Recorded in the task file for the reviewer.
- `.tab-strip` sets no `display` or `flex-wrap`. Hand-offs, Contributors and
  Usage wrap on purpose, and the Work tiles are a grid. The first version
  forced `nowrap` flex, and the census after the merge is what caught it.
- Tooltip's CSP proof is a browser test. It serves the document with
  `style-src-attr 'none'` and collects every `securitypolicyviolation`.
  Mutating the component to `setAttribute('style', …)` makes the test go red
  with two `style-src-attr` violations, so the instrument works. CSSOM writes
  are allowed and still show up in `getAttribute('style')`, so the test
  asserts that React renders no style, then the two custom properties, then
  the empty violation list.
