**Decisions**

- **A round's outputs are the refs in its own `summary_md`.** I added no `task_rounds.comment_id`.
  - The round has no column for its comment.
  - It does carry the comment's text, written in the same transaction and never rewritten.
  - That makes it the smallest link, and an edit of the comment cannot move a file between rounds.
  - CHIEF to record this in D-162.
- **Captions are the link text** the server writes, read back by `parseAttachmentCaptions`. I added no caption column.
  - A column would have changed `AttachmentView`.
  - The web mirrors that type (`view-type-drift`), so changing it would redden the web half before it exists.
- **`unlisted_work_id` is hand-edited to `ON DELETE set null`.**
  - drizzle-kit's SQLite `ADD COLUMN` dropped the action.
  - Without it, deleting a user — whose findings cascade — would fail on any finding that holds a file.
  - `migrate.test.ts` now asserts the FK.
- **A promotion moves files across projects.** A finding has no project, so its files were uploaded under any project the agent could upload to.
- **The secret check's limits:**
  - it scans the first 2 MiB of every text file, not only files up to 2 MiB;
  - masked and placeholder values pass, because D-162 asks for a masked copy;
  - a table header must be one or two words, so prose does not read as a CSV.
- **The `MCP_INSTRUCTIONS` proof list stays word for word.**
  - `server/web/test/.../connect-copy.test.ts` checks that the repo block contains it.
  - My first, shorter version would have reddened a web test.
  - I cut "Rules:" and "shared by" instead. The sentence ends at character 510.
