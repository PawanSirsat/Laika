**Decisions**

- **Eligibility.** Only your own agent, active, with a `full` grant, in a space whose agents are allowed. A `read_only` grant is refused separately, because that agent couldn't do the work.
- **Refusals** are 422 `unprocessable` with `details.reason`, in the `not_on_project` shape. §6.3's codes are closed.

- **`/agents/me/work-requests` is agent-token only.** A session or legacy token gets 403 `not_an_agent`. It is filtered in SQL to projects the agent can read now, so pages are never short.
- **`activity.agent_id` uses restrict, not set null.** A set-null cascade would be an UPDATE, and the append-only trigger refuses UPDATEs (LAI-135).
