**Decisions.**
- `6h 42m`, not `06:42`: LAI-830 retired clock-style durations.
- The timer state comes from `GET /me/time` because no timer-only read exists.
- A `409 timer_running` shows the running state rather than an error.
- A stop refused as `timer_too_short` discards the timer, because the server
  says nothing would be saved.

**Discovered.**
- The bar's geometry test passed 1 run in 3 on the latest master. The
  drawer slides in over 0.2s, and the columns and the bar were measured in
  separate calls while it moved, so the bar read 1.8px "above" the columns.
  The test now waits for the drawer's animations to finish and measures
  everything in one frame: 5 of 5 runs passed.
- The first draft of the theme work wrote both `backdrop-filter` spellings.
  The vite minifier then kept only `-webkit-backdrop-filter`, which Chrome
  ignores. That work was withdrawn by the owner and is not in this change.
- Owner-directed visual experiments in the same session (glass, sticky
  headers, palettes) were all withdrawn. None are in this branch.
