**Decisions.**
- **The headers live in an include snippet, not in each location.** A
  location with its own `add_header` (Cache-Control) loses every `add_header`
  inherited from the server block. So the snippet is included in the server
  block and in each location that sets a header. The test fails if any
  location sets a header without the include; the "removed from
  `/assets/`" mutation below was exactly that.
- **The CSP's two cases come from a `map`, not from substitution alone.** The
  server writes ` ${store}` or nothing. A bare `${LAIKA_STORAGE_ORIGIN}` after
  `data:` would need the space inside the variable. With the map, the operator
  sets a plain origin, and the off case is the attachments-off string with no
  stray space.
- **The reserved-path regex mirrors `isReservedPath`, not the brief's
  `^/(api|mcp|webhooks)(/|$)`.** The server reserves anything starting with
  `/mcp`, `/mcpx` included. The brief's regex would serve the SPA there.
  The test runs both on 17 paths and requires them to agree.
- **Two parity additions beyond the brief, both from the server's own
  behaviour.**
  - `*.map` answers 404 (LAI-722).
  - A missing `/assets/` file answers 404 instead of the document. The server
    falls through to the SPA there. Under nginx, a stale chunk would get HTML
    cached for a year, so failing is the safer answer. `Cache-Control` has no
    `always`, so a 404 is never marked immutable.
- **The test compares to `buildContentSecurityPolicy([], …)`, as briefed.**
  The server's own live CSP carries the fallback document's style hash in
  `style-src-elem`, because `app.ts` hashes `fallback.html` whether or not the
  SPA is built. nginx never serves that document, so it needs no hash. Its
  policy is the stricter of the two.
- **HSTS is sent on every response.** The server sends it only over HTTPS. A
  browser ignores it over plain HTTP, and the proxy terminates TLS.
- **The headers are compared against the middleware by running it.** A Hono
  app with `createSecurityHeaders` answers over `X-Forwarded-Proto: https`.
  The test takes away whatever the same app sends without the middleware, then
  compares names and values against the snippet. A header added to the
  middleware tomorrow turns this test red with no edit to the test.
- **`LAIKA_STORAGE_ORIGIN` is not a §11.7 row, and env-contract needs no
  exemption.** `env-contract.test.ts` reads compose and SPEC, not
  `docker/Dockerfile`'s ENV lines or `docker/web/`. It passed unchanged (11/11).
