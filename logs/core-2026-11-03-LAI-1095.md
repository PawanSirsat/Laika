**Decisions**
- Revoked agents are relabelled too: `backfillAgentDevices` relinks any agent whose label key is not its device's, so leaving them would move them back to a device with the old name at the next boot. A mutation that skipped them went red.
- A tool's name follows only when it is still `<anything> · <old name>` (the shape registering and *Add tool* give it), so a name the owner chose — the D-120 duplicates' — is kept.
- Rename sits in the device's Details panel, a section of its own, not the footer: the footer is the panel's one dangerous action (`SidePanel`), and the row is one line by design.
- No activity verb (D-122) and no migration: the columns exist.
- A refused save hands focus back to the name field. The first browser run caught it: *Save* is disabled under focus while it waits, focus fell to the page, and Escape no longer reached the form.
