**Decisions**
- Hand-written `@font-face` rather than `@import` of the package sheet. It is
  the only way to take latin alone, and the LAI-1125 pattern already did it
  for Commissioner.
- Italic is declared even though the UI hardly uses it. A browser fetches
  the italic file only when italic text is set, so it costs nothing until
  then. Without it, `<em>` would get a synthesised slant, which the owner's
  request (italic + upright) rules out.
