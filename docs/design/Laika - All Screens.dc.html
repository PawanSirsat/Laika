0Laika · complete screen inventory — handoff

Ten screens in one page, in build order. Everything is inline-styled and driven by one theme token set; the switch below flips every frame. Interactions are real where they carry meaning: board filters and the live SSE layer, panel tabs, promote-to-task, feed filters, proposal approve/reject with the apply bar, token create → shown-once → copy, role cycling.

RULES THAT DRIVE THE UI
Bot badge sits on the avatar corner — the work belongs to the person, the agent only wrote it.
Priority is a dot: P1 solid red, P2 solid amber, P3 hollow.
Statuses: backlog → todo → in progress → review → done.
Roles: Owner (one, transfer only) · Admin · Member · Viewer (read-only).
Viewer sees every screen but no write control.
1Laika · screen 1 — Kanban board

Same family as the reference board: light page, tinted lane tubs, white cards, Plus Jakarta Sans + JetBrains Mono for keys and counters. Three things are new and specific to Laika — a priority dot leading each card footer, a bot badge clipped to the assignee avatar when an agent did the last write, and a live layer that actually moves: the event stream in the rail advances on its own, and whichever card just changed carries a fading ring plus a "just now" stamp. 1a is live — toggle theme, filter to agent work, filter by person, watch a card update. 1b is the card anatomy, 1c the dark pair and the empty lane.
